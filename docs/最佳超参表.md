## 表 2 · 搜索空间，以及命中的值落在哪

| 超参 | DNN | CNN | RNN | ViT | CNN_attention |
|---|---|---|---|---|---|
| `lr`（对数均匀） | 1e-5 ~ 3e-3 → **1.79e-5**（贴下界⚠） | 1e-4 ~ 2e-2 → 4.04e-3 | 3e-5 ~ 5e-3 → 9.18e-5 | 1e-5 ~ 1e-3 → 1.52e-4 | 1e-4 ~ 1e-2 → 1.15e-4 |
| `weight_decay`（对数均匀） | 1e-6 ~ 1e-1 → 5.05e-3 | 1e-6 ~ 1e-2 → 2.3e-5 | 1e-6 ~ 1e-2 → 1.05e-4 | 1e-4 ~ 5e-1 → 1.31e-4（贴下界⚠） | 1e-6 ~ 1e-2 → 7.49e-6 |
| `dropout`（均匀） | 0 ~ 0.5 → 0.273 | 0 ~ 0.5 → 0.078 | 0 ~ 0.5 → 0.013（贴下界⚠） | 0 ~ 0.3 → 0.028 | 0 ~ 0.4 → 0.202 |
| `batch_size` | 32 / 64 / 128 → 32（最小⚠） | 32 / 64 / 128 → 32（最小⚠） | 32 / 64 → 64（最大⚠） | 32 / 64 → 32（最小⚠） | 4 / 8 / 16 → 8 |
| 结构参数 | `hidden_dim` 128/256/512 → **512（最大⚠）**；`bottleneck` 64/128/256 → 128 | `base_width` 32/64/96 → **64（中间）** | `rnn_hidden` 128/256/384 → **128（最小⚠）**；`hidden_dim` 128/256 → 256（最大⚠） | `embed_dim` 128/192/256 → **128（最小⚠）**；`depth` 4/6/8 → **8（最大⚠）**；`patch` 16/32 → 16（最小⚠） | `fnn_hidden` 128/256/512 → 128；`base_width` 32/64 → 64 |

⚠ = 命中的是搜索区间的端点，说明**这个方向可能还能往外扩**：
- DNN 的 lr 贴下界、hidden_dim 取到最大值 → 它想要「更小的 lr + 更大的容量」；
- ViT 的 depth 取到 8（最大）、embed_dim 取到 128（最小）、wd 贴下界 → 它想要「更深但更窄、更少正则」；
- RNN 的 rnn_hidden 取最小、dropout 贴下界 → 它想要「更小的模型、几乎不正则」（欠拟合的典型信号）；
- CNN 的三个主要旋钮（lr 4.04e-3、width 64、bs 32）都落在**区间内部**，说明它的最优区已经被包住了。

## 表 4 · 一个反常现象：RNN 的 search #1 没被采纳

搜索第 1 名（71.60%，lr 2.1e-4 / L2 / dropout 0.417 / bs 32）在正式训练里只有 **69.20%**；
第 2 名（lr 9.18e-5 / L1 / dropout 0.013 / bs 64）反而稳稳到 **71.40%**。

两组超参差异巨大（dropout 0.417 vs 0.013，层数 2 vs 1），验证集却只差 0.2 pt ——
**1 个样本 = 0.2 pt**，这个量级的差距在单次运行里不可分辨。选第 2 组还有两个额外理由：
它在无旋转时也测过（72.40%），且训练更稳（50 轮 vs 58 轮）。
