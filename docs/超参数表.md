# 超参数配置与最终验证结果

`val_acc` / `val_loss` 均为**最终正式训练**的数值：取按 val_acc 选出的最优权重（ckpt），
在 500 张验证集上评估的准确率，以及该轮对应的验证损失。
超参数是各模型 `cfg.py` 里**实际生效**的值。训练条件：至多 300 epoch，由 `EarlyStopping(val_loss, patience=12)` 终止。

---

## 表一：DNN 模型超参数配置与最终验证结果

| 参数 | DNN |
|---|---|
| val_acc | 64.20% |
| val_loss | 0.6431 |
| lr | 1.79e-05 |
| weight_decay | 0.00505 |
| dropout | 0.273 |
| batch_size | 32 |
| 结构 | hidden_dim 512, bottleneck 128 |

> 存档轮次 8；参数量 56.76 M；ROC-AUC 0.6846。
